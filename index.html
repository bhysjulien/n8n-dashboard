n8n Dashboard

A personal, self-hosted automation app.

n8n Dashboard is a private tool that runs on its owner's own computer using n8n. Each morning it builds a personal "Today" page with things like the weather, a dog-walk plan, upcoming calendar events, and emails that may need a reply.

It is used only by its owner. It is not a public service, and no one else can sign in to it.

With the owner's permission, it reads (but never changes, sends, or deletes) the owner's Gmail messages and Google Calendar events, so it can summarize them on the owner's private page.
