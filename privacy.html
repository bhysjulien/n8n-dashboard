Privacy Policy

n8n Dashboard · Effective October 5, 2026

Who uses this app

n8n Dashboard is a personal tool used only by its owner, on the owner's own computer. It does not offer accounts or services to anyone else.

What data it accesses

With the owner's permission through Google sign-in, the app requests read-only access to:

  • Gmail messages (gmail.readonly), to find emails that may need attention
  • Google Calendar events (calendar.readonly), to list upcoming events

The app cannot send, delete, or modify emails or calendar events.

How the data is used

Data is processed only on the owner's own computer, including by an AI model that runs locally, to produce a private daily summary for the owner. It is not used for advertising, profiling, or any other purpose.

Sharing and storage

Data is never sold, shared with, or sent to third parties. Summaries are stored only on the owner's computer. Google data is not transferred to any other service.

Google API Services User Data Policy

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions about this policy can be raised as an issue on this site's GitHub repository.
